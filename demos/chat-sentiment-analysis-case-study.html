fázis 01

Felmérés és feltanítás

Python · Anthropic Batch API · JSON export

Python Batch API Pandas JSON / CSV

A kiindulópont: exportált chatbot-naplók (JSON) és az emberi munkatársak által manuálisan felcímkézett adatok (CSV). A cél egy skálázható, reprodukálható gépi pipeline kiépítése, amely mindkettőt felváltja.

Batch API vs. real-time: 10 000 chatnél az aszinkron Batch API ~50%-os árengedményt ad — a feldolgozás 1–4 óra alatt fut le a háttérben, a Python script közben leáll. Egyszeri historikus futtatásnál ez a helyes választás.

Egy prompt, három kimenet chatenként:

Elemezd az ügyfél üzeneteit (a bot válaszait figyelmen kívül hagyva).

Ismert kategóriák: [szerviz időpont, árajánlat kérés, hibrid érdeklődés, trade-in, panasz/reklamáció, ...]

Adj meg:
— labels: 1–3 illő kategória a listából
— new_topic: ha van olyan téma, ami nem illik egyik kategóriába sem (max 3 szó), egyébként null
— sentiment: "pozitív" | "semleges" | "negatív"
— intensity: 1–5 (1=enyhe, 5=erős)
— emotion: "elégedett" | "érdeklődő" | "bizonytalan" | "frustrált" | "panaszkodó"

Válasz csak JSON-ban.
# Batch eredmény feldolgozása for result in client.messages.batches.results(batch_id): chat_id = result.custom_id parsed = json.loads(result.result.message.content[0].text) records.append({ "chat_id" : chat_id, "labels" : parsed["labels"], "new_topic": parsed["new_topic"], "sentiment": parsed["sentiment"], "intensity": parsed["intensity"], "emotion" : parsed["emotion"], })

Miért n8n és nem Python? Az éles pipeline nem egyszeri batch, hanem folyamatos eseményvezérelt feldolgozás. Az n8n vizuálisan menedzselhető, nincs szükség szerverre, és a webhook + HTTP Request kombináció elegendő — felesleges lenne Python script-et üzemeltetni ugyanerre.
