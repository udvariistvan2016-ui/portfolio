Case study · Speech-to-Text · LLM cleanup

Local Hungarian Speech-to-Text Pipeline with LLM Post-Correction

A privacy-first, CPU-only transcription workflow — benchmarked against a cloud service and refined with an LLM cleanup pass.

There was a recorded physiotherapy session, and the goal was to turn it into the most usable possible record of everything that was said — transcribed accurately, kept private, and produced at no cost. The whole pipeline runs locally on a modest laptop with no GPU.

  • 40 minsource audio
  • ~67 minCPU transcription
  • 2.9 GBlocal model · large-v3
  • €0cloud cost · fully local

The pipeline — hover a step for the code

Six steps, one notebook

01

Self-contained environment

A single uv project (Python 3.12, Jupyter) holds the interpreter, dependencies, ffmpeg, and the model weights in one folder — so the whole setup (the ~2.9 GB model included) is removable by deleting one directory.

show code 
# self-contained, easy to tear down
uv init --python 3.12
uv add faster-whisper pydub static-ffmpeg ipykernel jupyterlab
02

Chunk the audio

Split the recording into 10-minute MP3 segments so partial results appear during iteration instead of waiting for the full file.

show code 
audio = AudioSegment.from_file(HANGFAJL)
darab_ms = 10 * 60 * 1000
for i, start in enumerate(range(0, len(audio), darab_ms)):
    audio[start:start + darab_ms].export(
        DARABOK / f"resz_{i:03d}.mp3", format="mp3")
03

Transcribe locally on CPU

faster-whisper (large-v3) in int8. Disabling context conditioning removed hallucination loops and roughly halved the runtime — 40 minutes of audio transcribed in ~67 minutes on the CPU.

show code 
model = WhisperModel("large-v3", device="cpu",
                     compute_type="int8", cpu_threads=4)
segments, info = model.transcribe(
    str(darab), language="hu", vad_filter=True,
    condition_on_previous_text=False)   # kills repetition loops
04

Benchmark against the cloud

Cross-checked the local output against ElevenLabs Scribe. The cloud was cleaner on recurring domain terms and added diarization; the local model was competitive, unlimited and free — and correct where the cloud missed a domain term.

05

Correct with rules, then an LLM

A rule-based pass fixed the obvious recurring errors. Because the garbling shifts run to run, the robust step was an LLM cleanup (Claude Opus 4.8) that reconstructed correct Hungarian from the raw output.

show code 
JAVITASOK = {
    r"\bKézés\b": "Kilégzés",
    r"\bMegnyitózunk\b": "Megnyújtózunk",
    # ...
}
# then: LLM cleanup pass (Claude Opus 4.8) for the rest
06

Ship the deliverable

Exported the result into a single 7-page Word document: a 19-point exercise breakdown with the therapist’s correction principles, followed by the full transcript on a continuous mm:ss timeline.
